# Jingwei 开发指南

Jingwei 是面向端侧小模型的 Rust Agent 运行框架。它提供可组合的模型、工具、会话和运行时契约，由宿主决定业务目标、权限、模型与数据位置。

## 当前可用内容

现有框架可以装配自定义 Agent、受控文本模型调用、工具执行和会话日志。v0.1 正在逐步实现结构化模型交互、上下文预算、有限参考 Agent、任务预算及恢复能力。

[结构化模型协议](model-protocol.md)介绍第一批新增接口：类型化消息、工具关联、生成约束、能力预检和结果完整性检查。它们是已经实现的协议层，不代表现有适配器已能发送结构化请求。

## 阅读顺序

1. 查看[开发环境与兼容性](development.md)，了解当前源码版本和 Rust 要求。
2. 阅读[结构化模型协议](model-protocol.md)，理解模型输出和工具执行权限的边界。
3. 后续按实现进度补充受控模型入口、上下文、参考 Agent、预算及恢复教程。

本指南目前是可直接阅读的 Markdown，文档站构建配置和完整入门流程尚未交付。API reference 可从仓库运行 `cargo doc --workspace --no-deps` 生成；不要将这一开发快照当作已发布的完整 v0.1。
