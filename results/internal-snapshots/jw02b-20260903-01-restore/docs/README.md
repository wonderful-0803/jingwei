# 开发指南目录

本目录用于 Jingwei 开发指南，与框架 Rust 源码和 Cargo 包保持隔离。第一批内容已提供，可从 [指南概览](guide/src/index.md) 开始阅读；完整 v0.1 指南和文档站仍在开发。

## 目录职责

| 区域 | 用途 | 交付方式 |
| --- | --- | --- |
| workspace 的 crates 区域 | 框架源码与各 crate 的清单 | 公共源码；按各包边界发布 |
| 本目录的 guide 子目录 | 指南 Markdown、指南构建配置和必要文档资源 | 公共仓库，独立构建指南站，不加入 Cargo workspace members |
| 指南构建输出 | 生成的 HTML、搜索索引和缓存 | 可重建，不跟踪，不进入 Cargo 包 |
| 内部验证工程 | 独立示例、测试、fixtures、故障注入和原始评测资料 | 不公开交付，不作为公开指南或框架的构建依赖 |

后续指南内容统一放入 guide 子目录；本目录的其他内容默认仍被 Git 忽略，避免将内部设计和工程材料一并公开。

## 内容边界

- 指南保留学习 API 所需的说明和自包含教学代码片段，不提供独立示例项目或测试套件。
- 教学片段由内部流程验证；公开指南不能 include 或链接私有示例、测试数据与报告。
- API reference 来自 Rust 源码中的公共 rustdoc 注释；指南站不是框架的编译输入。
- 指南构建与 crate 构建互不依赖，删除指南目录不应影响框架消费者构建。
- crates.io 打包内容应逐包检查，不能将“Git 未跟踪”当作已经验证包内容的替代。

指南的具体构建工具、固定版本和构建入口将在文档工程准备完成后补充。
