# JW-07-b：本地持久任务状态存储

日期：2026-09-14。基于 dev / 4bfe14e；范围见 [JW-07 计划](JW-07-plan.md)，设计见 [ADR 0020](../adr/0020-file-task-state.md)。

## 实现

- 新增独立 jingwei-task-file，workspace 增至 22 个 crate。复用既有 serde/serde_json/Tokio，不新增第三方依赖，不进入默认 façade 或 task-state feature 的依赖图。
- FileTaskStateStore 实现 TaskStateStore，以每个任务绑定独立的既有普通文件保存连续 JSONL 快照链。OS 排他锁覆盖读链、验证、CAS、追加和同步；结构/兼容性/身份/单调性变化拒绝覆盖。
- Applied 和 AlreadyPresent 都要求同步确认；精确重试不重复追加。load 重新同步完整记录，未结束或损坏记录明确失败，不自动截断修复。写入前失败与写入结果不确定分别报告。
- 可配置单行、累计日志及已准入 IO 上限；Tokio blocking worker 拥有已接受作业，丢弃等待不撤销写入，clone 共享关闭状态，close 排空后台工作。
- 指南增加独立依赖、宿主供应文件、错误处理、提交顺序和生命周期示例，并作为私有 doctest 编译验证。

## 验证

新增 21 项私有测试入口（含子进程工作入口），覆盖文件重新打开、精确重试、竞争/错误身份、非法版本/兼容性、损坏与撕裂日志、容量、无 Tokio、关闭及放弃等待、跨进程 CAS 与锁释放、真实参考 Agent 完成/待答证据落盘。既有完整写入后退出测试扩展到任务适配器。

Linux GNU 故障验证使用既有私有夹具：内核文件大小限制产生零字节/部分 write 失败；同步前后错误在系统调用边界注入；完整写入后退出，再由无注入的新进程核验。部分尾部保持损坏并拒绝后续读写，完整候选重新同步后精确确认且字节不变。

九项基线全部通过，日志见 [20260914-160341-106980-g2pj8mh0](../../../results/baseline/20260914-160341-106980-g2pj8mh0/summary.json)。根 workspace 14 项，私有 workspace 371 项及指南 doctest 23 项，共 408 项。默认依赖树检查未引入文件适配器。指南根路径与 /jingwei/ 构建、Markdown 检查通过；各验证 21 个页面、908 条链接、3 项搜索查询，0 个公开源码文件。

## 边界与后续

宿主必须事先持久化文件及目录项，禁止运行期间替换、截断或绕过锁修改文件。存储 CAS 串行化不等同于断电原子追加；没有自动轮转、压缩和修复。部署需提供支持文件锁及 sync_all 的文件系统，尚未据此完成跨平台验收。

本批完成状态持久化，不代表完整 AT-F6 或 Agent 跨重启续跑完成。规范日志、预算与任务状态仍顺序提交，存储文件锁不授予执行权限。下一批 JW-07-c 接入受控状态协调、步骤/待答检查点及显式恢复；继续核对当前权限、日志和预算，不绕过 durable lease。
