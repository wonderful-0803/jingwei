# JW-04-d2-c1：安全边界上的宿主审计增额

日期：2026-09-04。分支：dev。开始时 HEAD 为 d2-a `96f83021ad66466609322a9d223f4c95f525b204`；在已有、未提交的 d2-b 上继续实现。本批没有 commit/push，没有更新 main、包版本、tag 或发布 Cargo 包。最新接续入口：[JW-04 计划](JW-04-plan.md)。

## 本批交付

- jingwei-budget 新增 grant_budget、BudgetGrantRequest/Record/Outcome/Error 与有界审计契约；jingwei-core 新增 BudgetOperationId，经 facade 既有模块导出。机制独立于具体 IO、Agent 策略、模型和业务审批。
- V3 检查点将新绝对上限与审计记录原子提交，记录操作 ID、操作者来源/理由、旧/新限制、原 revision/确认游标、原预算停止；V1 普通镜像与 V2 占用仍可读。事件和文件外层版本不变。
- 只允许 quiescent 且已核验规范日志的状态增额。原消耗、预留、未知用量、模式、ID 水位及活动/清理时间不变；仅针对相应资源增大的 ResourceLimit/ActiveTime 停止可被清除。
- 审计跨恢复、占用和后续 Turn 原样保留；同一边界续跑时仅逆向解释旧报告的限制/停止差异，不豁免消耗或日志核验。
- 同 ID、请求、原 revision/游标的重试返回 AlreadyApplied 历史回执；相同 ID 不同意图拒绝。失败保留确切候选与底层确定性，不返回执行句柄。
- 文件 CAS 和全链读取增加 validate_transition：保护旧审计前缀、拒绝无审计增额、拒绝在增额中夹带其他账本改变。自定义存储必须遵循同一契约。
- 审计上限为每 Task 64 条，单个操作 ID/actor/source/reason 最多 1024 UTF-8 字节。满额拒绝，不自动剪裁或重建 Task。

契约：[ADR-0010](../adr/0010-audited-budget-grants.md)。公开教程：[宿主审计增额](../../guide/src/budget-grants.md)。指南位于 docs/guide，独立测试位于 publish=false 的 tests/model-protocol，不作为框架源码编译输入。

## 未交付边界与下一步

这只是 d2-c 的第一批，不是 F4/F6 整体验收。默认 Session JSONL 尚无跨进程单写者保护；宿主需在整个增额期间持有独立所有权并提供真实持久历史，actor/source 只是审计标签，不替代认证。正在运行/遗留 claim 仍冻结；审计满额不提供归档入口。存储故障注入主要在契约层，损坏文件测试不等于真实 write/sync 系统调用失败或掉电。

下一步 d2-c2：先定义并验证 Session/恢复单写者所有权及旧执行者隔离，再分类处理遗留占用。保留精确候选时先核验原提交；有已记录请求但结果未确认、缺少 ID 水位或无法隔离旧进程时继续冻结。恢复转移必须关联原 execution_id/revision、操作者与确认日志证据，不自动重放工具。接续清单已写入 [JW-04 计划](JW-04-plan.md)。之后补实际文件故障、更多运行时崩溃窗口和 Linux 回归，完整 Task payload/等待用户状态及工具幂等性仍属 JW-07。
