# JW-07-a：版本化任务状态与证据校验

日期：2026-09-14。承接 dev / a272506；范围见 [JW-07 计划](JW-07-plan.md)，契约见 [ADR 0019](../adr/0019-versioned-task-state.md)。

## 实现

- 新增可选 `jingwei-task` crate，通过 façade 的 `task-state` feature 导出；默认关闭，不增加第三方依赖，也不自动安装进运行时。
- `TaskSnapshot` 保存版本、完整任务身份、兼容性声明、阶段、日志尾游标、已结算步骤、预算版本/累计用量和命名空间业务 payload。解码有大小及结构限制，独立证据验证核对最新预期身份、版本、兼容性、预算及规范日志。
- 只读日志评估识别未配对模型请求和工具调用，保留其原始意图地址；缺失结果或开放回合不能生成安全快照，不触发重试。
- `TaskStateStore` 提供按预期版本更新的可替换接口；有界内存实现支持原子竞争、精确重试、身份冲突及单调性检查。
- 预算检查点新增只读历史核验和恢复需求查询，既有执行所有权与恢复流程保持原有语义。

本批只支持空任务及完整结束回合边界。快照不授予执行权限，业务 payload 语义由宿主校验；内存存储不具备跨重启持久化能力。规范日志、预算检查点和任务状态按顺序提交，三者不是原子事务。完整恢复仍需后续批次。
