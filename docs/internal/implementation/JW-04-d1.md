# JW-04-d1：预算快照与恢复原语

日期：2026-09-04。状态：本批已实现并验证。开发基线：dev / d4bdf7d。关联 [ADR-0007](../adr/0007-budget-checkpoints.md) 与 [JW-04 计划](JW-04-plan.md)。本批是 d 的第一部分，不表示 AT-F4-04、完整 JW-04 或 F6 已验收。

## 本批实现

- jingwei-budget 新增 checkpoint 模块：独立数字版本 1、revision、事件地址、身份/额度/用量/活动时间、run、未决项与预留 ID 水位。模块仍无 IO/Tokio 依赖，不新增全局 provider 或业务状态。
- seal_checkpoint 原子采样并封存整个旧账本；所有 clone、scope、run、reservation 不能继续消费/结算，停止观察者被唤醒。封存不等于取消外部 IO；导出可继续的镜像之前仍须停止并排空工作。
- restore_checkpoint 检查版本化数据的不变量和宿主期望身份、revision、游标，采用新时钟起点并保留累计消耗。宿主限额仅能收紧，Hard/Soft 模式保持。它不自行证明存储最新性、事件持久化或排他恢复所有权。
- 有 run/pending 的镜像只恢复为冻结状态，保留 unknown、实际超额、结算溢出的原始证据和未决变量额度。不会重建旧句柄、退款或重放工具；重启后也不凭空累计未执行的清理耗时。
- BudgetCheckpointStore 提供异步 load/CAS 契约、精确重试结果与提交确定性分类。本批仅用测试 provider 验证契约，没有默认持久化适配器；validate_successor 不是跨进程 CAS。
- 新增独立指南和可编译教学片段，更新导航、PRD 与 M0 接续入口，避免继续使用上阶段的下一步描述。
