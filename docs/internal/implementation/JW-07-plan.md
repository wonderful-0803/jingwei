## 一致性方向

规范日志先确认，预算检查点继续通过既有所有权及 commit 屏障落盘，任务状态随后引用该精确预算版本和事件尾游标。后两者不是原子双写。任务状态落后时，由宿主在独占所有权下核对并重建框架派生字段；业务 payload 由应用 reducer/schema 决定，不能从旧 payload 猜测最新业务状态。状态写入失败不得导致历史工具重放。

首批只接受空状态或已结束的完整回合边界；步骤中间检查点和自动协调留在 c 批。缺失模型/工具结果由只读评估报告原始意图地址，拒绝捕获安全快照。内存状态存储不会安装到 StandardCoreBundle，也不替代持久预算存储。
