# JW-07-c：步骤暂停与受控任务续跑

日期：2026-09-14。基于 dev / b0c7a6e；关联 [JW-07 计划](JW-07-plan.md)、[ADR 0021](../adr/0021-controlled-task-continuation.md)。

## 实现

- 新增独立 jingwei-task-runtime，workspace 增至 23 个 crate；不进入默认 façade，复用既有依赖。TaskCoordinator 使用同一排他 Session provider、原持久预算 lease、任务状态存储、显式宿主权限策略与业务 reducer。
- 运行前核对完整日志、预算、身份、预期状态版本及当前兼容性，重新检查当前宿主策略；CAS 取得唯一执行占用后复查边界，canonical runtime 再核对自己的准入历史。持久执行不会降级到内存预算。
- 新增 Checkpointed 完整回合语义，贯通 Agent 输出、终态、预算报告、历史投影和任务相位。有限参考 Agent 可显式启用 checkpoint_each_step，在成功工具步骤后停止正文、完整收尾、顺序保存预算与任务状态。默认行为保持有限回合内循环。
- 宿主使用 Start / Continue / Reply 显式开启新回合；答复绑定准确的待答 TurnId。Completed 和 Stopped 不自动打开，Task 累计预算保留并与当前限制取严。框架不重新派发已确认调用，新的工具提案仍检查当前网关授权和审批。
- 执行结果与任务状态发布结果分开保留；失败状态 CAS 返回准确候选和底层确定性，允许精确重试而不重跑工具。预算收尾未确认时不发布安全任务状态，保留原 runtime 错误和预算候选。
- 已准入流程由后台 worker 拥有，drop 等待只分离，显式取消转发 runtime canceller，close 停止准入并排空执行及状态发布。通过 PluginRegistry 公开已选定 SessionPersistence 给可信宿主，确保整个流程使用同一所有者。

## 验证

新增 14 项私有测试入口（含一个子进程入口）：步骤暂停与历史结果投影、待答关联及新策略拒绝、兼容性/版本变化、当前工具授权、失败状态提交精确候选、实例容量与分离等待、取消前/运行中边界、独立协调器竞争、累计预算收紧、预算收尾失败、完成状态拒绝续跑和日志边界变化。

三个独立进程依次执行“工具步骤暂停 → 继续并提问 → 回复并完成”；每个进程使用新 runtime/provider/文件存储，最终状态版本 4，累计模型请求 3、工具调用 1、已结算决策 3。后两进程工具正文调用均为 0，原日志前缀保持一致。

最终九项基线全部通过，日志见 [20260914-162702-558040-7iunl9bg](../../../results/baseline/20260914-162702-558040-7iunl9bg/summary.json)。根 workspace 14 项，私有 workspace 385 项及指南 doctest 24 项，共 423 项。

[首轮基线](../../../results/baseline/20260914-162434-294268-zvqphgjp/summary.json)保留取消测试断言及 Clippy 锁作用域提示。取消正确语义为成功返回 Cancelled 报告，不是必然返回 Err；已修正测试，并将测试 MutexGuard 限定在 await 前的词法作用域，随后重跑全基线。

指南根路径和 /jingwei/ 构建、Markdown 检查通过；各校验 22 个页面、978 条链接、3 项搜索查询，未公开源码文件。默认依赖树未引入任务协调组件。

## 范围

步骤检查点通过关闭完整 Turn 实现，不承诺活动调用中间可以安全恢复。宿主策略及 payload reducer 是可信代码，需要独立核对当前实际契约与业务 schema；默认没有允许策略。存储错误不能触发模型或工具重放，旧任务状态落后时必须显式核对修复。

支持已确认步骤与待答边界的新进程续跑，不表示任意指令处崩溃恢复、介质掉电保证或完整 AT-F6 完成。跨新提案的工具幂等键与外部副作用核验继续在 JW-07-d，完整故障矩阵在 JW-07-e；保持 wonderful-0803 / dev。
