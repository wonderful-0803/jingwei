# ADR-0017：参考 Agent 的完成检查与连续重复边界

日期：2026-09-14。状态：接受。接续 ADR-0016，范围 JW-06-b / F3.6–F3.7。

保留 ReferenceAgent::new 的装配兼容性，以 with_checks 安装 ReferenceChecks。完成检查只接收 Task/Turn、模型声明和推理前状态版本；默认 Unverified，不从模型文本推断业务成功。宿主返回 Verified 时必须提供非空、有界证据引用；引用真实性及新鲜度由宿主负责。Rejected 第一时间停止，不隐式启动无限重试或消耗尚未实现的修正路径。

ProgressPolicy 使用每 Turn 连续重复阈值，默认 3。比较工具名、完整 JSON 参数、原始反馈及宿主状态版本；不比较每次生成的调用 ID、事件 ID 或推理序号。ReferenceState 默认未知，不能把 ordinal 当作业务状态变化。已确认结果和步骤报告先保留，再检测并停止，所以阈值包含已经执行的当前调用。

只保留一份前次观察，精确有界序列化比较，避免截断反馈造成假相等或哈希碰撞；默认 1 MiB，最高 16 MiB，超限失败且不重放已确认工具。明确的按工具轮询阈值仍受 max_steps、累计 Task 预算及取消约束。仅检测连续重复，交替循环由总步数约束。检测状态不跨 Turn 持久化。

所有宿主检查同步、非阻塞，不获得 runtime 工具、日志信封或预算增额接口。接口无法阻止宿主自行捕获外部能力，宿主实现仍属可信边界。业务验证不是 canonical 成功终态；后续持久化或能力收尾仍可能失败。

run_v1 添加默认可缺失的 completion/repeated_observations 字段，并扩展停止枚举。新读取器兼容旧报告，旧严格枚举读取器对新停止原因需升级。step_v1 保持不变，仍只记录模型动作事实。有限纠错与待答续跑契约留至 JW-06-c。
