# ADR-0007：预算快照与恢复原语

日期：2026-09-04。状态：JW-04-d1 已实现，验证见 [实施记录](../implementation/JW-04-d1.md)；JW-04-d 尚未全部交付。

后续修订：下文保留 d1 阶段的 V1 原语决策。d2-b 新增 V2 占用镜像与 runtime 协调，见 [ADR-0009](0009-durable-budget-execution.md)；V1 普通镜像仍可读取，不提供无审计解冻或增额。

## 分批边界

本批提供独立数字版本的 BudgetCheckpoint、导出时封存旧账本、严格恢复校验，以及可替换的异步 CAS 存储契约。账本本身仍不做 IO，不依赖 Tokio，不把 BudgetReport 当作恢复凭证。存储适配器、运行时写前保护、日志/快照一致性和审计增额留给 d2；不提供无审计的增额或解除冻结方法。

## 所有权与恢复

- seal_checkpoint 在账本锁内采样并封存，返回不可通过字段直接修改的快照。旧 TaskBudget 的所有 clone、scope、reservation、run 均不再消费或结算；导出失败不封存。调用方必须停止并排空工作后导出可继续的检查点，不能把封存当作取消外部操作。
- 快照保留身份、有效限额、token 模式、累计实际/估计/未知用量、已扣与已预留额度、活动/清理时长、停止原因、run 和未决项，以及单调递增的快照 revision 和预留 ID 水位。
- 恢复要求宿主提供期望身份、存储最新 revision、已核验的规范事件游标和当前宿主上限。游标仅用于精确匹配：本原语不访问日志，不能自行证明事件已提交、游标最新或不存在未记入快照的后续工作。数据必须来自可信存储，不能来自模型或工具输出。
- 宿主上限只能收紧快照限额，不能借恢复增额、重置计数或将 Hard 降为 Soft。新进程使用新的单调时钟起点；停机时间不计为活动时长。
- 只允许没有 run、没有 pending 的快照恢复为可执行账本；已有任务级停止原因不会清除。即使 run 已 prepare_report，但租约尚未 finish，仍按未结束运行处理。
- 带 run/pending 的快照可恢复为只读冻结账本，保留原始证据。无句柄重建、自动退款、清空未知用量或工具重放；冻结状态在重导出/恢复后仍保持，也不虚构重启后的清理时长。

## 存储契约

BudgetCheckpointStore 由宿主实现。load 必须返回所选 Task 的最新确认版本；compare_exchange 必须原子比较 expected_revision 并持久保存完整快照，首版以 0 表示不存在。后继必须为 expected_revision + 1，身份不可变。相同 revision 的精确重试可返回 ReplayedExact，不同内容必须冲突。错误区分确定未提交和提交结果不确定。

这不是一个默认文件 provider，也不把 trait 本身当作实际跨进程 CAS。未知提交结果必须先读取并核验原操作，不允许换 revision 盲重试。进程间单一恢复所有者、运行开始前的持久占用和崩溃窗口由 d2 实现；仅 load 后调用 restore_checkpoint 不能排除两个宿主同时恢复同一版本。

## 验证要求

验证版本/身份/revision/游标、畸形账目、严格宿主上限、旧句柄失效、未决冻结、时钟基准重建。使用实际子进程传递快照并继续扣费，证明快照原语能保留累计用量；该测试不是完整 AgentRuntime 或任意崩溃时刻的持久恢复验收。AT-F4-04、F6 和完整 JW-04 保持未完成。
